   Data Dictionary & Normalization Guide

   1. Leads Dataset Schema
Column Name           Data Type        Description

Lead_ID               String           Unique identifier for each lead.

Company_Name          String           The name of the prospective
                                       company.

Region                String           Geographic region (contains
                                       mixed cases/aliases).

Language              String           Primary language of the lead
                                       (contains mixed cases/aliases).

Industry_Vertical     String           Industry sector (e.g., Finance,
                                       Healthcare, Manufacturing).

Company_Size          Integer          Total employees. Can be
                                       blank/null. System must handle
                                       missing values.

Recent_Activity       String           The latest action taken by the
                                       lead.

VIP_Referral          Boolean          True/False flag for immediate
                                       Critical routing.
